# Frankfurt Falls

**A game by Diego Danylov.**

A floppy 3D rage-climber in the browser. Chef Le Grill has stuffed Frank's little hotdog buddies into a sack and locked them in a birdcage on the roof of his giant Food Tower. Climb four floors, answer the food gatekeepers' would-you-rathers (each answer adds a hazard to the floors above), beat three evil hotdogs on the bridges, then stomp the Chef's hat on the roof.

- **Play:** https://game-frankfurt-falls.vercel.app
- **Play on Claude:** https://claude.ai/artifact/CDiRLv1HnFyZ8WbKNkr5Qc
- **More of Diego's games:** https://diego-games.vercel.app
- **Code:** https://github.com/ydanilov/game-frankfurt-falls

Single HTML file, three.js 0.147 (+ OutlineEffect) from jsDelivr, Google Fonts (Lilita One, Bangers, Nunito), painted backdrops in `assets/`. No build step.

## Controls

| | Keyboard | Gamepad | Touch |
|---|---|---|---|
| Move | WASD / arrows | left stick | drag on the left side |
| Jump | Space | ✕ | JUMP |
| Charged jump | hold Shift | hold □ | hold CHARGE |
| Camera | mouse drag, Q E R F, wheel | right stick | drag on the right side |
| Zoom | V | R3 | ZOOM |
| Bridge fights | J shoot · K slap · G grab crate | R2 · △ · ○ | SHOOT · SLAP · GRAB |
| Pause | P / Esc | Start | II button |
| Menus | arrows + Enter, Esc back, Q/E shop tabs | d-pad/stick + ✕, ○ back, L1/R1 shop tabs | tap |

Coins from the tower ledges buy hats, buns, skins and trails in **Frank's Closet**. Progress is saved in your browser (`localStorage`).

## Files

- `src.html` — the game (source of truth; artifact body that starts at `<title>`)
- `index.html` — the same game as a full web page, generated by `tools/build-index.sh`
- `assets/` — 7 painted 1024×572 WebP menu backdrops (title, shop, 4 story panels, victory) and 4 painted sky panoramas (one per floor)
- `tools/` — Playwright tests

## Run the tests

```bash
cd tools
npm install          # playwright ^1.63 + three@0.147.0 for offline runs
npm test             # builds tools/test.html, then boot, menus, run, mobile
```

Screenshots land in `tools/shots/`. Tests use headless Chromium with SwiftShader WebGL.
